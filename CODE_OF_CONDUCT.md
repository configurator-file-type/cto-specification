# Code of Conduct

Under Section 18 of the Project Charter, the **Joint Development Foundation Code
of Conduct** applies to all participation in this Project:
<https://jointdevelopmentfoundation.org/policies/code-of-conduct>

It applies in every Project space: this repository, Slack, email, meetings and
events.
