About this non-normative example
This illustrates the experimental CTO parameter draft pinned to 271b221…; it does not adopt or change a specification. Fixtures are abstract, synthetic boxes, not manufacturer products. The viewer shows only literal bounds and a source-declared void—no framing, material detail or native CAD regeneration.
The dashed envelope is obtained by resolving the input maxima together, only when that combination resolves. It does not certify all intermediate combinations. Rules still apply to every accepted change. A fixed resolved file opens as a fixed box without being relabeled to another CTO version. Use the original source file to retain editability.
Opening fields follow the pinned draft: the legacy name offset_z_ft is the vertical offset from the bottom, mapped to local Y here. Published 0.2 files are not silently assigned that draft interpretation. There is no engineering, fabrication, Registry publication or CIS approval.
